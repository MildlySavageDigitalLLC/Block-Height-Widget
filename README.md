# Bitcoin Block Height Widget

A real-time Bitcoin block height widget that displays the latest block height using the mempool.space API. The widget is mobile-friendly and features interactive animations for a more engaging user experience.

## Features
- Real-time Bitcoin block height updates every 10 seconds.
- Manual refresh option with a fun animated "building blocks" display.
- Responsive design, works on both desktop and mobile.

## Usage
1. Visit the [GitHub Pages link](#) (replace this with the live link) to view the widget.
2. Add it to your phone's home screen for easy access (Android/iOS supported).
